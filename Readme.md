# Mini Hospital Emergency Management System

## Description

This project is a Java-based Mini Hospital Emergency Management System developed using different data structures.

## Data Structures Used

- Binary Search Tree (BST) - Patient Records
- Queue - Emergency Patient Management
- Stack - Treatment History
- Singly Linked List - Patient Visit History

## Main Features

- Add, search and delete patients
- Display patients using in-order traversal
- Add and treat emergency patients
- Manage treatment history
- Manage patient visit history
